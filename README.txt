Версия программы: embedded-candidate-v1.

Состав
- lab.py: встроенная программа из карточки, без исправлений.
- Задание.txt: полный текст опубликованного задания, включая правила, каталог и оценивание.
- data/catalog.csv: тот же каталог из карточки в удобном формате CSV; программа берёт данные из lab.py.
- evidence/: папка для ваших фактических результатов.

Запуск
1. Распакуйте ZIP в отдельную папку.
2. Откройте терминал в папке с lab.py.
3. Проверьте Python: python --version. Нужен Python 3.10 или новее.
4. Запустите: python lab.py
5. Сохранить вывод первого собственного случая: python lab.py > evidence/C01.txt
Если в вашей системе Python вызывается как python3 или py, замените python в командах на соответствующую команду.

Внешние пакеты, сервер, PHP, база данных и доступ к сети для запуска не нужны.
Меняйте только items, promo и fulfillment в конце lab.py, как указано в задании. Для каждого случая сохраняйте входные данные и фактический вывод. До завершения фиксации результатов не исправляйте кандидат.

Сегодняшний объём определяется разделом «Первая пара: 90 минут» в Задание.txt. Раздел «Вторая пара» выполняется отдельно.

Ограничения этого варианта, уже описанные в карточке: нет reference, веб-интерфейса и сортировки. Сверяйте ожидания с правилами, а не с программой. Во второй паре вместо сортировки проверяется ZERO×1; reference не запускается, потому что в этом варианте его нет.

README — только памятка по запуску. Новых требований к заданию она не добавляет. Готовых ответов, исправленной программы и преподавательских ключей в архиве нет.
